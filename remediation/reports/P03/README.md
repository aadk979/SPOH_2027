# P03 reports

Artefacts behind `findings/F03-code-quality.md`. Every file here is regenerated by a command below,
run from the repo root. Product code is unchanged by P03.

| File                                | Step  | Command                                                                                                                                                                                                                |
| ----------------------------------- | ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `server-modules.dot` / `.svg`       | P03.1 | `npx depcruise server/src --config .dependency-cruiser.cjs --include-only '^server/src' --output-type dot --collapse '^server/src/(modules/[^/]+\|lib/[^/]+\|middleware\|config\|jobs\|generated\|types\|[^/]+[.]ts)'` |
| `jscpd-report.json`                 | P03.3 | `npx jscpd@5.3.2 server/src client/src packages/shared/src --ignore "**/generated/**,**/*.test.ts,**/*.test.tsx" --min-tokens 50 --reporters json --output <dir>`, then prettier                                       |
| `server-files.dot` / `.svg`         | P03.1 | `npx depcruise server/src --config .dependency-cruiser.cjs --include-only '^server/src' --exclude '^server/src/generated' --output-type dot`                                                                           |
| `module-map.json` / `module-map.md` | P03.1 | `node remediation/reports/P03/module-map.mjs` (uses `exports.mjs`; exits 1 if an export has no target), then `npx prettier --write remediation/reports/P03`                                                            |
| `run-repros.sh`                     | P03.4 | `bash remediation/reports/P03/run-repros.sh [filter]`: runs `server/tests/{integration,unit}/repro/*` and `client/tests/repro/*` with `.skip` removed; before a fix every repro fails                                  |
| `test-gaps.json`                    | P03.6 | coverage run in `test-gaps.mjs`'s header, then `node remediation/reports/P03/test-gaps.mjs <coverage-final.json>`                                                                                                      |
| `backlog.md`                        | P03.2 | `node remediation/reports/P03/backlog.mjs` (exits 1 unless every P00 function has one plan), then prettier                                                                                                             |
| `shared-map.json`                   | P03.8 | `node remediation/reports/P03/shared-map.mjs`                                                                                                                                                                          |

**Rendering the SVGs.** This container has no Graphviz binary, so the `.dot` files are rendered
with the WebAssembly build of Graphviz, installed outside the repo so no dependency is added:

```bash
mkdir -p /tmp/gv && (cd /tmp/gv && npm init -y >/dev/null && npm i @hpcc-js/wasm-graphviz@1.29.1)
cat > /tmp/gv/render.mjs <<'JS'
import { Graphviz } from '@hpcc-js/wasm-graphviz';
import { readFileSync, writeFileSync } from 'node:fs';
const g = await Graphviz.load();
for (const f of process.argv.slice(2)) writeFileSync(f.replace(/\.dot$/, '.svg'), g.dot(readFileSync(f, 'utf8')));
JS
node /tmp/gv/render.mjs "$PWD"/remediation/reports/P03/*.dot
```
