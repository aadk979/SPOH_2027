# Reviewed generated catalogue history restores — partial P10.8

The generated event/station catalogue now offers reviewed restores for each
supported operational key's available history. Labels, descriptions and units
come from the generated registry. A review names the selected historical version,
validated historical result, current scoped value, inheritance and selected/source
versions. A required bounded reason and deliberate confirmation accompany the
shared restore request schema. No arbitrary JSON/value/provenance field is sent.

Restoring a saved value appends a new version through the existing guarded API.
Restoring RESET removes the selected override using current inheritance, without
reconstructing an unknown historical inherited value. An already inherited scope
explains why it has no override to remove. Unavailable history offers no restore.
Archive blocks fresh requests while still permitting the existing API's owned
historical retry. This slice adds no backend, shared contract, schema or worker.
Private product, privacy, attendance security and platform settings retain their
specialised paths and are excluded by the existing operational selection.

The capture review/retry implementation is extracted into shared settings hooks;
capture's behaviour and copy remain unchanged. Pending/ambiguous requests freeze
one body/UUID and lock fields, scope, collapse and review navigation. Retrying
reuses that intent. A nonpermission current-read failure retains an ambiguous
review rather than unmounting it, but blocks fresh requests. Denial clears the
owner's private values and remains sticky above query observers. Event/person
changes remount a collapsed owner.

Current-value, selected-version or source-version/scope changes require a new
review. Reloading the review clears its reason, confirmation and prior intent.
Array values compare by contents: the initial test exposes reference comparison
incorrectly treating identical refetched severities as changed. Primitive capture
and schedule consumers retain their existing comparison behaviour.
