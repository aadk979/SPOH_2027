## Lessons that cost time today

- **`git commit` commits everything staged.** `git rm` and `git mv` stage at once. Before a narrow
  commit run `git diff --cached --stat`. (This broke `main` once today.)
- **A Cedar action asked of the wrong resource type silently denies.** Check
  `packages/access-policies/schema.cedarschema` `appliesTo` first: `Settings.ManageEvent` and the
  other setting actions take a `Setting` resource (`settingQuestion(key)`); `Schedule.Manage`,
  `Structure.Edit`, `Settings.Read`, `Report.*` take the `Event`; `Announcement.SendStation` a
  `Station` (`stationCandidates`); `Self.Read` the caller's `Membership`.
- **New event routes need:** an isolation case in `server/tests/integration/isolation.test.ts`
  and the matrix regenerated (`UPDATE_ROUTE_MATRIX=1` on `routeRoleMatrix.test.ts`, then Prettier
  on `route-role-matrix.json`).
- **Lint limits:** function complexity ≤ 10, ≤ 3 parameters, ≤ 80 lines; split into helpers or
  hooks. `check:hardcoding` rejects a bare `spoh` prefix in source (`@spoh/…` is fine).
- **Client tests** mock `@/features/session`; add
  `...(await import('../helpers/permissions')).permissionHooks(() => permissionsFor([...]))`.
  The UI kit's `Field` takes a render function child.
- **CDK:** cdk-nag findings are acknowledged with `Validations.of(x).acknowledge({ id, reason })`
  and evidence; `app.test.ts` and `appInfrastructureConfig.test.ts` pin the deploy role's actions
  and the task's plain environment.
- **Server config** keys are counted in `server/tests/unit/config.test.ts` and listed in
  `server/.env.example`.
